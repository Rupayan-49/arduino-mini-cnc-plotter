# Arduino-Based Mini CNC Plotter

## Project Overview
This project demonstrates a low-cost mini CNC plotter
using Arduino and stepper motors to draw designs on paper.

## Features
- Low-cost CNC plotting system
- Arduino-based control
- Stepper motor movement
- GRBL-based motion control

## Hardware Components
- Arduino board
- Stepper motors
- Motor driver modules
- CNC frame and mechanical parts
- Power supply
- Pen holder

## Software Requirements
- Arduino IDE
- GRBL firmware
- Compatible G-code sender

## Project Files
- 3D part designs
- Circuit diagram
- Project presentation
- Project report
- GRBL-related files

## How to Use
1. Assemble the hardware.
2. Install the required firmware.
3. Connect the Arduino to your computer.
4. Configure a compatible G-code sender.
5. Upload a design and test the plotter.
